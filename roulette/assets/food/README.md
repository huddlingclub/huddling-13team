# 카테고리 아이콘

여기에 3D 아이콘 파일을 아래 이름으로 넣으면 우측 목록과 결과 모달의 썸네일이 그 파일로 바뀝니다. 파일이 없으면 카테고리 색 위에 선 아이콘이 나옵니다.

- 형식: `.png`, `.webp`, `.svg`, `.jpg` 중 하나. 배경이 투명한 정사각 이미지, 256px 이상을 권장합니다.
- 썸네일은 64px 정사각이고, 아이콘은 그 안에 76% 크기로 들어갑니다. 배경색은 [lib/foodStyles.ts](../../lib/foodStyles.ts)의 `tint`입니다.
